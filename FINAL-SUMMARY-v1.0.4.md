## 🔧 CODE BLOCK DETECTION

### How It Works

**WordPress sends:**
```html
<pre class="wp-block-code">
  <code class="language-javascript">
    const hello = 'world';
  </code>
</pre>
```

**Frontend detects:**
1. Parse class: `language-javascript`
2. Extract: `javascript`
3. Display badge: `JAVASCRIPT`

**Supports:**
- Gutenberg Code Block ✅
- Prismatic Plugin ✅
- SyntaxHighlighter ✅
- Highlight.js ✅
- Custom formats ✅
